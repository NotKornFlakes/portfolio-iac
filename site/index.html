How I build

I use Claude, Anthropic's AI assistant, to build faster. Then I read, test and document everything myself before I hand it over. Your project lives in a GitHub repository you own, with a guide for how it works and what to do if it stops.

  • Secure by default. Each automation gets the least access it needs. Passwords and keys aren't stored in plain text, and data isn't kept longer than the job needs.
  • Reliable. I test with real examples, and anything that runs on its own tells someone when it fails.
  • Yours to keep. The code, accounts and tools stay in your name, and everything is documented, so you aren't locked into me.
  • Permission in writing. I don't touch a system without written agreement on what's allowed.
  • No kickbacks. I don't earn commissions on tools I recommend. Free and open-source comes first.
  • Separate from my day job. This is independent work, done on my own time and equipment.

What's in my wheelhouse. I'm open to new projects now. My wheelhouse is small, well-scoped work: one workflow, one tool, one check-up. I'm not a 24/7 IT provider, a penetration-testing firm or a compliance auditor. If you need one of those, I'll help you find someone who can.

How it works

  1. Email me with a sentence or two about what you need.
  2. I reply with questions or an honest answer. If an existing tool already does the job, I'll tell you.
  3. A call, only if we need one: a Proton Meet video call or a regular phone call, whichever you prefer.
  4. A written plan before any work starts: what I'll build, what access it needs, and what you'll get.
  5. Build, test and hand over, in a GitHub repository you own, with a short guide on how it works and what to do if it stops.
